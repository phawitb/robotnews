# หุ่นยนต์ครับ — ข่าวหุ่นยนต์ภาษาไทย

เว็บ local ที่ได้รับแรงบันดาลใจจาก robot-new.com มีค้นหา หมวดหมู่ แหล่งข่าว เรียงวันที่ แบ่งหน้า อ่านสรุป แชร์ลิงก์ และโหมดสีเข้ม

## เปิดใช้งาน

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจ

```sh
npm start
```

เปิด http://localhost:4173 — ใช้ `PORT=4174 npm start` หากพอร์ตไม่ว่าง

รายการข่าวใช้ข้อมูลหลักจาก `content/articles.json` และสร้างข้อมูลหน้าแรกผ่าน `npm run build` รูปภาพและฟอนต์บางส่วนโหลดจากอินเทอร์เน็ต เนื้อหามีเครดิตและลิงก์ต้นฉบับ

เส้นทาง `/` และ `/news/?category=industrial-robots` ใช้งานได้ ลิงก์ `?article=hirebotics` เปิดสรุปข่าวโดยตรง

## หน้าอ่านข่าวละเอียด

ทุกข่าวเปิดหน้าแยกใต้ `/articles/<id>.html` มีสรุปภาษาไทยแบ่งหัวข้อ รูปขนาดเต็ม เครดิต และรายการวิดีโอทั้งหมดที่พบในเนื้อหาบทความ โดยตัดภาพโฆษณา ข่าวแนะนำ และรูปซ้ำออก

- ข้อมูลพื้นฐาน: `content/articles.json`
- เนื้อหาเรียบเรียงภาษาไทย: `content/details.json`
- รายการรูปและวิดีโอพร้อมที่มา: `content/media.json`
- หลังแก้ข้อมูลให้รัน `npm run build` และ `npm run check`

แหล่งข่าวมีภาพรวม 16 ภาพ และวิดีโอที่อ้างอิง 30 รายการ คลิป YouTube โหลดเมื่อกดเล่น สื่อที่ถูกจำกัดการฝัง/เข้าถึงมีลิงก์กลับต้นฉบับ กรณีไม่มีรูปหรือวิดีโอในเนื้อหาต้นฉบับจะระบุไว้ตามจริง การเล่นสื่อภายนอกขึ้นกับเจ้าของเว็บไซต์และการเชื่อมต่ออินเทอร์เน็ต

การรวบรวมครั้งนี้ทำแบบบันทึกข้อมูล ไม่ใช่ระบบดึงหรือแปลข่าวอัตโนมัติ สคริปต์ใน `scripts/` สำหรับการรวบรวมใช้ Firecrawl CLI และ Python/BeautifulSoup (ไม่จำเป็นสำหรับการเปิดเว็บปกติ)

## Deploy บน Vercel

เชื่อม GitHub repository แล้ว deploy ได้โดยใช้ `vercel.json` ที่กำหนดให้เป็น static website:

- Framework Preset: Other (`framework: null`)
- Build Command: `npm run build`
- Output Directory: `dist`

Vercel เสิร์ฟไฟล์ HTML, CSS และ JavaScript ที่สร้างไว้โดยตรง ส่วน `server.mjs` ใช้เฉพาะเปิดเว็บบนเครื่อง เส้นทาง `/news` และ `/news/` ถูกส่งไปหน้ารวมข่าวโดยยังใช้ตัวกรองจาก query string ได้


## ลงข่าวรอบใหม่ด้วย skill

Skill อยู่ที่ `skills/robotnews-daily/SKILL.md` และติดตั้งใน personal skills ชื่อ `$robotnews-daily` เรียกเพื่อคัดข่าวใหม่ 10 ข่าวจากอย่างน้อย 3 สำนัก เขียนรายละเอียดภาษาไทย ตรวจรูป/วิดีโอและข่าวซ้ำ แล้วตรวจเว็บและ push ไป main อัตโนมัติ พร้อมตรวจ Vercel ยังไม่มีการตั้งเวลารายวัน

ประวัติข่าวและรอบนำเข้าอยู่ใน `content/news-history.json` ตัวนำเข้าปฏิเสธข่าวซ้ำที่บันทึกไว้และทำซ้ำรอบเดิมโดยไม่เพิ่มข่าวซ้ำ การตรวจความซ้ำเชิงเนื้อหาและความครบถ้วนของสื่อต้องทำโดยผู้ใช้ skill ด้วย หากข่าวใหม่ที่ผ่านเกณฑ์ไม่ครบ 10 ข่าว จะเก็บร่างและไม่เผยแพร่ชุดที่ไม่ครบ

```sh
npm run news:check -- .news-work/YYYY-MM-DD.json
npm run news:apply -- .news-work/YYYY-MM-DD.json
npm run build
npm run check
```

สคริปต์ตรวจ/นำเข้าไม่ push เอง ขั้นตอน skill ตรวจผลและ commit/push หลังผ่านการตรวจทั้งหมด ดูรูปแบบข้อมูลใน `skills/robotnews-daily/references/batch-format.md`
